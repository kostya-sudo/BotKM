VK BOT - List_Cm
================

1. Установите Python 3.11+.
2. Откройте терминал в папке List_Cm.
3. Выполните: pip install -r requirements.txt
4. Откройте config.json и вставьте НОВЫЙ токен сообщества VK.
5. Запустите: python main.py

Владелец бота настроен через VK username: a.chelovech
Бот сам получает числовой VK ID через VK API при запуске.

Важно: токен не хранится в этом архиве. Не публикуйте его и не отправляйте другим людям.
